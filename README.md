# Bozontos Dallamok – demo

Statikus Bootstrap 4.6 weboldal a kapott látványterv alapján.

## Struktúra

- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/` – képek

A Bootstrap és a Google Fonts CDN-ről töltődik.

## GitHub Pages

A projekt gyökerét töltsd fel egy GitHub repository-ba, majd a repository Settings → Pages alatt kapcsold be a GitHub Pages-t a megfelelő branch / root könyvtárból.
